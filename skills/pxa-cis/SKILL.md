# cis — 識別系統的取值規則 v0.1

> 📋 版本變更見 `CHANGELOG.md`。

定位：顏色、字型、標誌的單一來源。其他 skill 只引用這裡的「角色名稱」，不寫色碼；
要換識別時只換品牌包，其他 skill 不用改。

## 1. 值從哪裡來

本 repo 公開，不放任何單位的名稱、標誌與識別規範。值分兩處：

| 位置 | 內容 | 性質 |
|---|---|---|
| `defaults/brand.json`（本 skill 內） | 中性預設值：色碼、字型；單位名稱與標誌欄位留空 | 公開 |
| `%USERPROFILE%\.pxa\brand\brand.json`（品牌包） | 實際的單位名稱、規範色、字型、標誌檔名、品牌範本檔名 | 私有，不屬於任何 repo |

取值順序：

1. 讀 `defaults/brand.json`。
2. 品牌包存在時再讀品牌包的 `brand.json`，同名欄位以品牌包為準，沒寫的欄位沿用預設值。
3. 在回報中說明這次用的是品牌包還是中性預設值。

品牌包的內容不寫進本 repo，也不貼進會公開的文件。

## 2. 品牌包的內容

| 檔案 | 用途 |
|---|---|
| `brand.json` | 值（欄位見 §3） |
| `logo_color.png`、`logo_white.png` | 全彩標誌、反白標誌（有向量檔時另放 `.svg`） |
| `pxa_presentation_template.potx` | 含標誌的簡報範本（由 `pxa-presentation` 的 `scripts/build_template.ps1` 產生） |
| 識別規範原檔（PDF） | 標誌比例、留白、禁用方式的依據 |

同仁要使用品牌版時，把整個 `.pxa\brand\` 資料夾複製到自己電腦的同一位置。

## 3. `brand.json` 的欄位

| 欄位 | 內容 |
|---|---|
| `name` | 這組值的名稱（`neutral` 或品牌代號） |
| `org.name_zh`、`org.name_en` | 單位名稱；中性預設值留空 |
| `color.*` | 品牌色與版面色（§4） |
| `role.*` | 圖用的角色色（§5） |
| `band.*` | 圖的分層橫帶底色（§5） |
| `font.*` | 字型（§6） |
| `logo.*` | 標誌檔名與使用限制（§7） |
| `template.presentation` | 品牌簡報範本的檔名 |

色碼一律六位十六進位、不加 `#`。

## 4. 品牌色與版面色

| 角色名稱 | 用在 | 中性預設值 |
|---|---|---|
| `color.primary` | 標題、表頭、深色頁底色、論述框 | `0957C3` |
| `color.secondary` | 次要強調、圖表第二序列 | `307FE2` |
| `color.ink` | 內文 | `1B2733` |
| `color.muted` | 次要文字、來源註、頁尾 | `5F6B76` |
| `color.surface` | 卡片底色 | `EEF3F6` |
| `color.line` | 框線、格線 | `C9D3DA` |
| `color.accent` | 唯一的強調色，只用在需要注意的項目 | `F2A541` |

- 版面上的顏色只用這七個角色；要新增角色先改本表，不在個別文件裡自行加色。
- 簡報、文件的顏色一律取佈景主題色（或樣式），不在個別物件上寫死色碼。
- 圖內的角色色（§5）不受「唯一強調色」限制。

## 5. 圖用的角色色

圖的顏色代表方塊的角色，不代表品牌，所以放在公開的預設值裡，各單位共用。

| 角色名稱 | 代表 | 底色 | 框線 | 文字 |
|---|---|---|---|---|
| `role.data` | 資料、參數、輸入與輸出 | `FDE39E` | `B5892B` | `1B2733` |
| `role.model` | 模型、次系統、模型運算 | `C3E6B6` | `4F9A44` | `1B2733` |
| `role.core` | 全圖的核心（唯一的主模型、運動方程式） | `5B4AA8` | `3F3380` | `FFFFFF` |
| `role.deliverable` | 用途、交付、下游 | `DBD7F1` | `5B4AA8` | `1B2733` |
| `role.script` | 腳本、設計、設定 | `C9DFF5` | `3F78B5` | `1B2733` |
| `role.decision` | 判斷（菱形） | `EDEDED` | `7F7F7F` | `1B2733` |
| `role.flag` | 貼在方塊角落的小標籤（切換旗標等） | `FBDCD6` | `B5433A` | `1B2733` |

| 角色名稱 | 代表 | 底色 |
|---|---|---|
| `band.model` | 分層橫帶：模型層 | `EDF8EB` |
| `band.script` | 分層橫帶：腳本層 | `EBF2FD` |
| `band.data` | 分層橫帶：資料層 | `FDF4E0` |
| `band.deliverable` | 分層橫帶：產出層 | `F2F0FC` |
| `band.group` | 群組外框的底色 | `FAFAFC` |

- 底色取自維護者認可的一組既有圖（由圖片取色）；框線色是目視估計，待拿到原始檔後核對。
- 一張圖只用到的角色才列進圖例；`role.core` 一張圖最多一到兩個方塊。
- 圖怎麼畫（工具、語法、版面）屬 `pxa-diagram`。

## 6. 字型

| 角色名稱 | 用在 | 中性預設值 |
|---|---|---|
| `font.zh` | 中文（標題與內文） | Noto Sans TC（思源黑體） |
| `font.latin` | 英數 | Noto Sans TC |
| `font.fallback_zh` | 電腦沒有 `font.zh` 時 | Microsoft JhengHei |
| `font.mono` | 程式碼、檔名、旗標 | Consolas |

- 交付給別人用的範本（`.potx`、`.dotx`）在佈景主題裡寫 `font.zh`；對方電腦沒有時由軟體自行替換，
  交付時在回報中提醒要安裝字型。
- 字級屬各產出自己的規則（簡報見 `pxa-presentation` §5.1），不在本 skill。

## 7. 標誌

| 規則 | 說明 |
|---|---|
| 來源 | 只用品牌包內的標誌檔；沒有品牌包時不放標誌，也不用文字假造 |
| 版本 | 淺色底用全彩標誌，深色底用反白標誌 |
| 比例 | 等比例縮放，不拉伸、不裁切、不改色、不加外框或陰影 |
| 留白與可用底色 | 依品牌包內識別規範的規定（寫在品牌包 `brand.json` 的 `logo.clear_space`、`logo.backgrounds`） |
| 位置 | 由各產出的範本決定（簡報：母片右上，封面與章節頁用反白版） |
| 對外文件 | 是否放標誌、放哪一個單位的標誌，由負責人決定，不自行判斷 |

## 8. 誰來這裡取值

| skill | 取什麼 |
|---|---|
| `pxa-presentation` | 佈景主題的顏色與字型、標誌、品牌範本 |
| `pxa-diagram` | 圖用的角色色、分層橫帶色、字型 |
| `pxa-scribe`（docx 轉檔）、`pxa-matlab-project`（README.html） | 尚未改為引用本 skill，見 CHANGELOG 待辦 |

## 9. 回報格式

用到本 skill 的產出，回報時附一行：
`識別：<品牌包名稱 或 中性預設值>；標誌：<有 / 無>；字型：<實際使用的字型>`。
