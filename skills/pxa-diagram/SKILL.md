# diagram — 方塊圖、架構圖、流程圖、時序圖的畫法 v0.1（草稿）

> 📋 版本變更見 `CHANGELOG.md`。
> **本 skill 尚未完成**：圖的規則、依圖種選工具、匯出、檢查已定；原始檔在專案中的位置、泳道圖與腳本產生示意圖的範例尚未定案（§11）。
> 被呼叫時先告知使用者這一點；圖要存進專案時，先就 §11-d 與使用者確認位置，不自行決定。

定位：報告（`pxa-scribe`）、簡報（`pxa-presentation`）、專案說明書（`pxa-matlab-project`）共用的畫圖規則。
顏色與字型向 `pxa-cis` 取值，本 skill 不寫色碼。

## 1. 範圍

| 圖種 | 回答的問題 | 特徵 |
|---|---|---|
| 方塊圖、軟體與系統架構圖 | 系統由哪些部分組成、資料怎麼流 | 方塊＋箭頭；可用群組外框表示一個檔案或一個系統的內部 |
| 控制架構方塊圖 | 回授迴路怎麼接、訊號經過哪些環節 | 方塊＋加法點；回授線固定走下方，往左回到加法點 |
| 流程圖 | 一步一步怎麼做、哪裡會迴圈 | 有先後順序；判斷用菱形；迴圈與重試用虛線 |
| 時序圖 | 誰在什麼時候、以什麼頻率把什麼傳給誰 | 參與者一欄一個，由上往下是時間；重複的段落用 `loop` |
| 狀態圖 | 系統有哪些狀態、什麼條件下切換 | 狀態＋轉移條件 |
| 泳道圖 | 哪一層（或誰）負責哪一步 | 橫帶分層，欄是階段 |
| 資料驅動示意圖 | 依數字畫出的時間關係或幾何（多速率執行網格、模式時間軸） | 位置由數字換算，不用目測排 |

其他圖種（V 模型、甘特圖、風險矩陣等）不在本版範圍。

## 2. 動筆前先定四件事

1. **這張圖回答哪一個問題**：一張圖只回答一個；回答不了的內容另畫一張。
2. **圖種**：依 §1 選。
3. **方向**：資料流由左到右；階層與相依由上到下；一張圖只用一個主方向。
4. **角色**：列出每個方塊屬於哪個角色（§4）；分不出角色的方塊，多半是這張圖混了兩個問題。

## 3. 方塊

| 規則 | 說明 |
|---|---|
| 形狀 | 圓角矩形；判斷用菱形；其餘形狀不用 |
| 文字 | 兩行：第一行粗體是名稱，第二行較小是說明、檔名或方法；沒有第二行可省略 |
| 字數 | 名稱以十二個中文字內為度；說明一行寫完，寫不完表示該拆方塊或移到圖說 |
| 檔名與程式名 | 照原文，不翻譯；路徑用專案實際的寫法 |
| 尺寸 | 同一層、同一角色的方塊同寬同高；彙總多個上游的方塊可以加寬對齊上游 |
| 對齊 | 同層方塊上緣對齊、間距相等 |

## 4. 顏色：依角色，不依美觀

角色與色碼見 `pxa-cis` §5。本 skill 只規定怎麼用：

| 角色 | 用在 |
|---|---|
| `role.data` | 資料、參數、輸入與輸出 |
| `role.model` | 模型、次系統、模型運算 |
| `role.core` | 全圖的核心；一張圖最多一到兩個 |
| `role.deliverable` | 用途、交付、下游 |
| `role.script` | 腳本、設計、設定 |
| `role.decision` | 判斷菱形 |
| `role.flag` | 貼在方塊右上角的小標籤 |

- 同一份文件裡，同一個角色永遠同一個顏色。
- 顏色只表示角色，不用來表示重要性或狀態；要強調就用 `role.core`，不另外加色。
- 圖放在白底上；圖內配色不受簡報「唯一強調色」的限制。

## 5. 連線

| 規則 | 說明 |
|---|---|
| 線型 | 直角折線，帶箭頭；不用斜線與曲線 |
| 實線 | 主流程、主要資料流 |
| 虛線 | 回授、迴圈（下一個 case）、重試、次要或旁路的資料流 |
| 雙向箭頭 | 只用在「呼叫並取回結果」的關係（例如腳本與它執行的模型） |
| 線上文字 | 只在不標就看不懂時才標：分歧的條件（是／否）、迴圈的原因、線上傳的是什麼 |
| 交叉 | 盡量不交叉；避不開時調整方塊順序，不用跨線符號 |
| 匯流 | 多條線進同一個方塊時，先匯成一條幹線再分支 |

## 6. 圖例、分層、群組、小標籤

| 元素 | 規則 |
|---|---|
| 圖例 | 每張圖都有，放在圖的左下；只列這張圖用到的角色；文字用該圖的說法（例如「資料與參數」「包裝模型」） |
| 分層橫帶（泳道圖） | 淡色橫帶，左側寫層名；色碼見 `pxa-cis` 的 `band.*`；欄標題寫「編號＋階段名」 |
| 群組外框 | 虛線圓角外框，底色 `band.group`，左上角寫群組名稱（例如檔名） |
| 小標籤 | 膠囊形，貼在方塊右上角，等寬字型；標示影響該方塊的切換旗標或選項 |
| 區段小標 | 多列對照時，每列上方可放一個小字標題（例如「配平」「線性化」） |

## 7. 文字與範例

- 中文優先；技術術語、檔名、函式名保留原文。
- 圖內不放長句；需要解釋的內容寫在圖說或內文。
- 圖要有圖說：「圖 N　這張圖回答的問題」。報告內的編號規則依 `pxa-standards`。
- 本 repo 公開：skill 內的範例一律用虛構代號（例如 `uav01mk20.slx`），不沿用實際專案的檔名與型號。

圖要「看得懂細節」，靠的是內容：

| 做法 | 說明 |
|---|---|
| 線上標實際傳遞的名稱 | 訊號名、topic 名、檔名、變數名照原文，不寫「資料」「輸出」這類泛稱 |
| 方塊寫出位置與頻率 | 第二行寫檔名、模型路徑或執行頻率（例如 `~200 Hz`、`事件觸發`） |
| 狀態只用三種樣式 | 實心＝執行且輸出被採用；虛線框＝在跑但輸出不被採用或只用一部分；細線＝停止；圖例要列 |
| 圖說附種類 | 圖說後加圖種（方塊圖、時序圖…），讀者先知道怎麼讀 |
| 圖下附一段說明 | 寫圖中省略了什麼、頻率是標稱值還是實測、細節在哪份文件 |

## 8. 工具：依圖種選

| 圖種 | 工具 | 原始檔 | 範本與範例 |
|---|---|---|---|
| 時序圖 | Mermaid `sequenceDiagram` | `.mmd` | `templates/diagram_template.mmd`、`examples/sequence_cycle.mmd` |
| 流程圖 | Mermaid `flowchart`（ELK 排版） | `.mmd` | `templates/diagram_template.mmd`、`examples/flow_retry.mmd` |
| 狀態圖 | Mermaid `stateDiagram-v2` | `.mmd` | `templates/diagram_template.mmd` |
| 方塊圖、軟體與系統架構圖、控制架構方塊圖 | 手寫 SVG | `.svg` | `templates/diagram_template.svg`、`examples/block_folder_flow.svg` |
| 泳道圖 | 手寫 SVG | `.svg` | `templates/diagram_template.svg` |
| 資料驅動示意圖 | 腳本產生 SVG | `.py`（產生 `.svg`） | 待補 |

- Mermaid 負責「排版靠演算法比較整齊」的圖：參與者多、分支多、線會交叉。
- SVG 負責「位置本身有意義」的圖：迴路走向、加法點、分層、對齊，自動排版會打亂。
- 一張圖混了兩種性質時，先拆成兩張圖，不在 Mermaid 裡硬調位置。

**SVG 軌（§8.1–§8.3）**：起點一律是 `templates/diagram_template.svg`：複製、改檔名，只填「方塊」「連線」「圖例」三段，
`<style>` 與 `<defs>` 不改。

### 8.1 畫布與座標

| 規則 | 說明 |
|---|---|
| 畫布 | `<svg>` 寫 `viewBox="0 0 1000 H"` 與同值的 `width`、`height`；寬固定 1000，高依內容取 10 的倍數 |
| 座標 | 全部取 10 的倍數（文字基線除外）；同一欄的方塊 `x` 相同，同一列的方塊 `y` 相同 |
| 間距 | 同列方塊之間 30；欄與欄之間留出放幹線的空間（約 30–60） |
| 留邊 | 四周各留 10 |
| 標題 | 第一個子元素是 `<title>`，寫這張圖回答的問題 |
| 字型 | 寫在根元素：`font-family="'Noto Sans TC','Microsoft JhengHei',sans-serif"` |

### 8.2 class 對照

色碼只寫在範本的 `<style>` 裡，值取自 `pxa-cis` `defaults/brand.json`；方塊與文字只掛 class，不寫 `fill`、`stroke`。

| class | 用在 | 對應 `pxa-cis` |
|---|---|---|
| `bx` ＋ `data` / `model` / `core` / `dlv` / `script` | 方塊（`rect`） | `role.data` / `role.model` / `role.core` / `role.deliverable` / `role.script` |
| `bx dec` | 判斷菱形（`path`） | `role.decision` |
| `bx flag` | 小標籤膠囊（`rect`，`rx` 為高的一半） | `role.flag` |
| `band-model` / `band-script` / `band-data` / `band-dlv` | 泳道橫帶 | `band.*` |
| `grp` | 群組虛線外框 | `band.group` |
| `t1`、`t2` | 方塊的名稱（粗體 15）、說明（11.5） | — |
| `inv` | `core` 方塊上的文字改白色 | — |
| `tf` | 小標籤內的等寬字 | `font.mono` |
| `th` | 泳道的欄標題、群組名稱 | — |
| `e`、`e2` | 實線、虛線連線 | — |
| `el` | 線上文字 | — |
| `lg` | 圖例文字 | — |

### 8.3 元素寫法

| 元素 | 寫法 |
|---|---|
| 方塊 | `<rect class="bx 角色" x y width height rx="14"/>`；高 70 時名稱基線在上緣下 28、說明在下 50，`x` 取方塊中心 |
| 判斷 | `<path class="bx dec" d="M中,上 L右,中 L中,下 L左,中 Z"/>`，文字置中 |
| 小標籤 | 膠囊壓在方塊右上角框線上，膠囊中心線對齊方塊上緣 |
| 連線 | `<path class="e" d="M… H… V…">` 只用 `M`、`H`、`V`；終點停在方塊邊外 2，加 `marker-end="url(#ah)"` |
| 匯流與分支 | 先畫一條到幹線的線，再畫幹線（單一 `V`），每個分支各一條 `H` 加箭頭 |
| 線上文字 | `<text class="el">` 放在線段上方 8 |
| 圖例 | `<g transform="translate(10, 底部)">`，每項是 26 × 16 的小方塊（`rx="4"`）＋文字，項距 90–120 |

### 8.4 Mermaid 軌

起點一律是 `templates/diagram_template.mmd`：複製、改檔名，檔頭 `config` 與 `classDef` 段不改，只改圖的內容。

| 規則 | 說明 |
|---|---|
| 版本 | 固定 `mermaid@11.4.1` 與 `@mermaid-js/layout-elk@0.1.7`；改版本要重看所有範例 |
| 檔頭（每個 `.mmd` 都寫） | `theme: base`、`fontFamily`、`themeVariables`；值對應 `pxa-cis` §4（`color.surface`、`color.muted`、`color.line`、`color.ink`）與 §5（`band.*`） |
| 排版（不寫在檔頭） | ELK、`NETWORK_SIMPLEX`、`MODEL_ORDER`、直線、`htmlLabels: false`、時序圖欄寬 170，寫在 `scripts/mmd2svg.ps1` 的 `initialize`；Mermaid 11.4.1 不採用檔頭裡的這些設定 |
| 角色色 | 方塊掛 `:::data`、`:::model`、`:::core`、`:::dlv`、`:::script`、`:::dec`、`:::flag`，`classDef` 的值對應 `pxa-cis` §5 |
| 宣告順序 | 節點依流程先後宣告；ELK 依宣告順序判斷哪條是回頭線，順序錯會整張圖左右顛倒 |
| 雙向線 | 不用 `<-->`；「呼叫並取回」畫成一條單向實線，線上寫取回什麼 |
| 方塊文字 | 名稱與說明用換行分兩行；不寫 `<br/>`、不寫 HTML |
| 字元 | 標籤內不寫 `<`、`>`、`&`；改寫成文字（「小於」） |
| 時序圖 | 用 `autonumber`；參與者名稱附頻率；觸發方式、保持方式寫在訊息後的括號；`Note over` 說明前提 |

### 8.5 腳本產生 SVG

用在由數字決定位置的示意圖（多速率執行網格、模式時間軸、機體俯視等）。

- Python 腳本放在輸出的 `.svg` 旁邊，同名（`<圖名>.py` → `<圖名>.svg`）；數字一改就重跑，不手改輸出的 SVG。
- 輸出沿用 SVG 軌的 `<style>`、class 與畫布規則（§8.1–§8.3），配色同樣只掛 class。
- 數字（頻率、時刻、幾何）寫在腳本開頭的一個區段，並註明來源。

## 9. 匯出

| 用途 | 格式 | 做法 |
|---|---|---|
| 原始檔 | `.svg`、`.mmd`、`.py` | 版本控制只追原始檔；由 `.mmd`、`.py` 產生的 SVG 與所有 PNG 可重產 |
| Mermaid → SVG | `.svg` | `scripts/mmd2svg.ps1 -Mmd <檔案>`：Edge 無頭模式執行 Mermaid，取出 SVG 並補上寬高；需要連到 `cdn.jsdelivr.net`（只下載程式庫，不上傳內容） |
| HTML（導讀、專案說明書） | 嵌入 `.svg`；或在頁面上即時渲染 `.mmd` | 即時渲染時 `initialize` 用與 `mmd2svg.ps1` 相同的設定，並在無法連網時顯示原始碼 |
| `.docx`、`.pptx` | `.png`，放大 2 倍 | `scripts/svg2png.ps1 -Svg <檔案>`；`mmd2svg.ps1` 加 `-Png` 可一次做完 |

- 放進 `.pptx` 時用 PNG，不轉成 PowerPoint 原生圖形；在簡報裡要改圖，回頭改原始檔再轉一次。
- 原始檔改了一定要重轉；文件裡的圖與原始檔不一致視為錯誤。

## 10. 檢查

每張圖轉成 PNG 後逐張看過才交付：

| # | 檢查 |
|---|---|
| 1 | 文字沒有超出方塊，也沒有貼到框線 |
| 2 | 每個箭頭都接進方塊邊緣，沒有停在空白處 |
| 3 | 連線沒有穿過方塊與文字；線上文字沒有壓到線或方塊 |
| 4 | 同欄同列的方塊對齊、同寬同高 |
| 5 | 顏色與角色一致；`core` 不超過兩個 |
| 6 | 圖例只列這張圖用到的角色，說法與圖內一致 |
| 7 | 範例與公開文件裡沒有實際專案的檔名、型號 |
| 8 | Mermaid 圖：主流程方向正確（沒有左右或上下顛倒）；線上文字沒有被截斷或斷字 |
| 9 | Mermaid 圖：方塊顏色來自 `classDef`，沒有未掛角色的預設灰底方塊（判斷以外） |
